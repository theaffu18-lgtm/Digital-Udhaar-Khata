# 🚀 Digital Udhaar Khata

A modern AI-powered MERN stack finance management system for shopkeepers and small businesses.

Digital Udhaar Khata helps shop owners manage:

* Customer credit records
* Transaction ledgers
* AI-powered business insights
* PDF financial reports
* Smart dashboard analytics

---

# 🌟 Features

## 🔐 Authentication

* User Registration
* User Login
* JWT Authentication
* Protected Routes

---

## 👥 Customer Management

* Add Customers
* View Customers
* Track Customer Credit
* Search Customers

---

* Balance Tracking

# ⚙️ Installation

## Clone Repository

```bash
git clone https://github.com/theaffu18-lgtm/Digital-Udhaar-Khata.git
```

---

# 🔥 Backend Setup

```bash
cd backend

npm install

npm run dev
```

Create `.env`

```env
MONGO_URI=your_mongodb_url

JWT_SECRET=your_secret

PORT=5000
```

---

# 🔥 Frontend Setup

```bash
cd frontend

npm install

npm run dev
```
